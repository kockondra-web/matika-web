Exponenciální a logaritmické rovnice a nerovnice

Řešení exponenciálních rovnic srovnáním základů i substitucí, definice logaritmu a práce s logaritmickými výrazy, řešení logaritmických rovnic a nerovnic.

Exponenciální rovnice

Základní věta
$$\forall a\in\mathbb{R}^+\setminus\{1\}\ \ \forall x,y\in\mathbb{R}: \qquad a^x=a^y \iff x=y$$ Když se ti povede obě strany rovnice převést na stejný základ, stačí porovnat exponenty.
Příklad
\(3^x=9\)
\(3^x=3^2\)
\(x=2\)
Příklad
\(4^{2-3x} = \sqrt[5]{0{,}125}\)
\(0{,}125 = \dfrac18 \Rightarrow 2^{4-6x} = 2^{-3/5}\)
/ převést na základ 2
\(4-6x = -\dfrac35\)
\(x=\dfrac{23}{30}\)
Příklad
\(3^{6x+4} = 3^{1-5x}\cdot 3^{\frac{3x-12}{5}}\)
\(6x+4 = 1-5x+\dfrac{3x-12}{5}\)
/ srovnat exponenty
\(x=-\dfrac{27}{52}\)
Příklad
\(3^{x-1}-2(\sqrt3)^{2x+2}+51=0\)
\(3^x\cdot\dfrac13 - 2\cdot3^{x+1}+51=0\)
/ \((\sqrt3)^{2x+2}=3^{x+1}\)
\(3^x\left(\dfrac13-6\right) = -51\)
/ vytknout
\(3^x = 9\)
\(x=2\)

Rovnice řešené substitucí

Když se v rovnici objeví stejný výraz s exponentem \(x\) i \(2x\) (nebo \(x\) v různých členech se stejným základem), pomůže substituce \(t=a^x\) — rovnice se změní na kvadratickou v \(t\).

Příklad
\(2^{2x-1}+4^{x-5}=513\)
\(4^x\cdot\dfrac12 + 4^x\cdot\dfrac{1}{1024} = 513\)
/ vše na základ 4
\(4^x\left(\dfrac12+\dfrac1{1024}\right)=513\)
\(4^x = 513\cdot\dfrac{1024}{513} = 1024 = 2^{10}\)
\(2x=10\)
\(x=5\)
Příklad
\(3\cdot2^{x-\frac32}+5\cdot2^{x+\frac12}=46\)
\(3\sqrt{\dfrac18}\cdot2^x + 5\sqrt2\cdot2^x = 46\)
/ rozepsat mocniny
\(2^x\left(\dfrac{3\sqrt2}{4}+5\sqrt2\right)=46 \Rightarrow 2^x\cdot\dfrac{23\sqrt2}{4}=46\)
\(2^x = \dfrac{46\cdot4}{23\sqrt2} = \dfrac{8}{\sqrt2}=4\sqrt2=2^{5/2}\)
\(x=\dfrac52\)
Příklad · substituce
\(16^x-50\cdot2^{2x}=896\)
\(t=2^{2x}: \qquad t^2-50t-896=0\)
/ \(16^x=(2^{2x})^2\)
\(t_{1,2}=64,\ -14\)
\(2^{2x}=64=2^6 \Rightarrow x=3\)
\(2^{2x}=-14\)
nemá řešení
\(x=3\)
Příklad · substituce
\(\dfrac83\cdot3^{x-1}+1=9^{x-1}\)
\(t=3^x: \qquad -t^2+8t+9=0 \Rightarrow t^2-8t-9=0\)
/ vynásobit 9, upravit
\(t_{1,2}=9,\ -1\)
\(3^x=9\Rightarrow x=2, \qquad 3^x=-1\)
nemá řešení
\(D=\mathbb{R},\quad P=\{2\}\)
Příklad · substituce
\(4^{x+1}+3\cdot2^{2x+4}=30\)
\(4\cdot2^{2x} + 48\cdot2^{2x} = 30\)
/ vše na základ 2
\(2^{2x}\cdot52=30 \Rightarrow 2^{2x}=\dfrac{15}{26}\)
\(2x=\log_2\dfrac{15}{26}\)
\(x=\dfrac12\log_2\dfrac{15}{26}\)
Příklad · substituce
\(2^{2x+3}+9=9\cdot2^{x+1}\)
\(8\cdot2^{2x} + 9 = 18\cdot2^x\)
\(t=2^x: \qquad 8t^2-18t+9=0\)
\(t_{1,2}=\dfrac34,\ \dfrac32\)
\(x_1=\log_2\dfrac34, \qquad x_2=\log_2\dfrac32\)

Logaritmus a jeho vlastnosti

Definice
$$\log_a x = y \iff a^y=x, \qquad \forall a\in\mathbb{R}^+\setminus\{1\},\ \forall x\in\mathbb{R}^+,\ \forall y\in\mathbb{R}$$
Věty pro počítání s mocninami (připomenutí)
$$a^r\cdot a^s = a^{r+s} \qquad a^r:a^s=a^{r-s} \qquad (a^r)^s=a^{r\cdot s}$$
Věty pro logaritmy
\(\forall x,y\in\mathbb{R}^+,\ \forall a\in\mathbb{R}^+\setminus\{1\}\): $$\log_a x + \log_a y = \log_a(x\cdot y) \qquad \log_a x - \log_a y = \log_a\left(\frac{x}{y}\right)$$ $$\log_a x^r = r\log_a x\ \ (\forall r\in\mathbb{R}) \qquad \log_a\sqrt[r]{x} = \frac1r\log_a x\ \ (\forall r\in\mathbb{R}^+)$$
Věta pro změnu základu
$$\log_a c = \frac{\log_b c}{\log_b a}$$ Hodí se, když chceš logaritmus spočítat na kalkulačce, která umí jen \(\log\) (základ 10) nebo \(\ln\) (základ \(e\)), ale potřebuješ jiný základ.

Rozklad a sloučení logaritmů

Příklad · číselný
\(\log20+\log50\)
\(=\log(20\cdot50)=\log1000=3\)
Příklad · rozklad výrazu
\(\log\left(5a\cdot\sqrt[3]{b^2}\right)\)
\(=\log(5a)+\log\left(b^{2/3}\right)\)
/ log součinu
\(=\log5+\log a+\dfrac23\log b\)
Příklad · rozklad výrazu
\(\log\left(\dfrac{5x^4y^3}{\sqrt[3]{a^2b}}\right)\)
\(=\log(5x^4y^3) - \log\sqrt[3]{a^2b}\)
/ log podílu
\(=\log5+4\log x+3\log y-\dfrac23\log a-\dfrac13\log b\)

Odlogaritmování (sloučení do jednoho logaritmu)

Opačný postup: máš součet/rozdíl logaritmů (i s číselnou konstantou) a chceš je sloučit do jednoho výrazu pod jedním logaritmem. Konstantu převedeš na \(\log_a(a^k)\) se stejným základem, a pak použiješ věty pro součet/rozdíl obráceně.

Příklad
Sluč do jednoho logaritmu: \(4\log_{1/2}x^3 - 3+\log_{1/2}\sqrt z\)
\(-3 = -\log_{1/2}\dfrac18\)
/ protože \((1/2)^3=1/8\)
\(=\log_{1/2}x^{12} - \log_{1/2}\dfrac18+\log_{1/2}\sqrt z\)
/ \(4\log x^3=\log x^{12}\)
\(=\log_{1/2}\left(8x^{12}\sqrt z\right)\)
Příklad
Sluč do jednoho logaritmu: \(\dfrac34\log_3(m-1) - \dfrac16\log_3(m-1) - 4+\log_32\)
\(=\log_3\dfrac{(m-1)^{3/4}\cdot2}{(m-1)^{1/6}\cdot81}\)
/ \(-4=\log_3(3^{-4})=\log_3\frac1{81}\)
Stejný zlomek jde zapsat i pomocí odmocnin: \(\dfrac{2\sqrt[4]{(m-1)^3}}{81\sqrt[6]{m-1}}\).
\(=\log_3\left(\dfrac{2(m-1)^{7/12}}{81}\right)\)

Logaritmické rovnice

Základní věta
$$\forall x,y\in\mathbb{R}^+\ \ \forall a\in\mathbb{R}^+\setminus\{1\}: \qquad \log_a x=\log_a y \iff x=y$$
Příklad
\(\log_3(2-x) = -\log_3(3x+1)\)
Podmínky: \(2-x>0\) a \(3x+1>0 \Rightarrow x\in\left(-\dfrac13,2\right)\)
/ definiční obor
\(2-x = (3x+1)^{-1}\)
/ \(-\log_3 A=\log_3 A^{-1}\)
\((2-x)(3x+1)=1\)
\(3x^2-5x-1=0\)
/ upravit na kvadratickou
\(x_{1,2}=\dfrac{5\pm\sqrt{37}}{6}\)
Oba kořeny (\(\approx1{,}85\) a \(\approx-0{,}18\)) leží v definičním oboru \(\left(-\frac13,2\right)\), takže jsou oba platné.
\(x_{1,2}=\dfrac{5\pm\sqrt{37}}{6}\)
Příklad
\(\log x^2+\log\sqrt x+\log x=10\)
\(2\log x+\dfrac12\log x+\log x=10\)
/ \(\log x^r=r\log x\)
\(3{,}5\log x=10\)
\(\log x=\dfrac{20}{7}\)
\(x=10^{20/7}\)

Smíšená exponenciálně-logaritmická rovnice

Když se v rovnici mocní i logaritmuje zároveň a základy se nedají snadno srovnat, pomůže zlogaritmovat obě strany a využít \(\log a^r=r\log a\), čímž se z exponentů stanou obyčejné koeficienty.

Příklad
\(\dfrac{\sqrt[3]{4^{2x-5}}}{9^{1-x}} = 3^{5x+1}\cdot8^{x-5}\)
\(\log\sqrt[3]{4^{2x-5}} - \log9^{1-x} = \log3^{5x+1}+\log8^{x-5}\)
/ zlogaritmovat obě strany
\(\dfrac{2x-5}{3}\log4 - (1-x)\log9 = (5x+1)\log3+(x-5)\log8\)
/ \(\log a^r=r\log a\)
\((4x-10)\log2-(6-6x)\log3 = (15x+3)\log3+(9x-45)\log2\)
/ \(\log4{=}2\log2,\log9{=}2\log3,\log8{=}3\log2\), krát 3
\(-5x\log2-9x\log3 = -35\log2+9\log3\)
/ sloučit členy s \(x\)
\(x = \dfrac{35\log2-9\log3}{5\log2+9\log3}\)
\(x\approx1{,}076\)

Nerovnice

Příklad
\(\dfrac{1}{27} < \left(\dfrac13\right)^{3x-1} \leq 3\)
\(3^{-3} < 3^{1-3x} \leq 3^1\)
/ vše na základ 3
\(-3 < 1-3x \leq 1\)
/ základ >1, znaménko zůstává
\(-4 < -3x \leq 0 \ \ /:(-3)\)
/ dělení záporným číslem otáčí nerovnost
\(\dfrac43 > x \geq 0\)
\(D=\mathbb{R}, \qquad P=\left\langle0,\dfrac43\right)\)
Příklad
\(|x|^{x^2-x-2} \leq 1\)
\(\ln|x|^{x^2-x-2} \leq \ln1 = 0\)
/ zlogaritmovat (podmínka \(x\neq0\))
\((x^2-x-2)\ln|x| \leq 0\)
\((x-2)(x+1)\cdot\ln|x| \leq 0\)
/ rozložit, znaménková tabulka
Kritické body: \(x=-1\) (kde \(x+1=0\)), \(x=0\) (vyloučeno definičním oborem), \(x=1\) (kde \(\ln|x|=0\)) a \(x=2\) (kde \(x-2=0\)). Znaménková tabulka na těchto čtyřech bodech dá výsledný interval.
\(D=\mathbb{R}\setminus\{0\}, \qquad P=\{-1\}\cup\langle1,2\rangle\)
Příklad
\(2^{x+2} \leq 12\sqrt2+2^x\)
\(4\cdot2^x - 2^x \leq 12\sqrt2\)
\(3\cdot2^x\leq12\sqrt2 \ \ /:3\)
\(2^x\leq4\sqrt2=2^{5/2}\)
\(x\leq\dfrac52\)
