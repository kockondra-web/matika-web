Goniometrické vzorce, rovnice a nerovnice

Přehled všech vzorců, které se hodí znát, dopočítávání zbylých funkcí z jedné známé hodnoty a metody řešení goniometrických rovnic — od základních po ty se substitucí.

Základní vzorce

Definiční a jednotkové
\(\operatorname{tg} x = \dfrac{\sin x}{\cos x}\),   \(x \neq \frac{\pi}{2}+k\pi\)   ·   \(\operatorname{cotg} x = \dfrac{\cos x}{\sin x}\),   \(x \neq k\pi\)
\(\sin^2 x + \cos^2 x = 1\)   ·   \(\operatorname{tg} x \cdot \operatorname{cotg} x = 1\)
Nejdůležitější vzorec vůbec
\(\sin^2 x + \cos^2 x = 1\) se používá skoro v každém příkladu — a to v obou směrech: jako \(1 - \cos^2x = \sin^2x\) i naopak. Když si v úpravě nevíš rady, zkus ho jako první.

Součtové vzorce

Sinus a kosinus součtu a rozdílu
$$\sin(x \pm y) = \sin x \cos y \pm \sin y \cos x$$ $$\cos(x \pm y) = \cos x \cos y \mp \sin x \sin y$$
Pozor na znaménka u kosinu
U \(\cos\) se znaménko obrací: \(\cos(x+y) = \cos x\cos y - \sin x\sin y\). U \(\sin\) zůstává stejné jako v zadání.
Vzájemný převod
$$\sin x = \cos\left(x - \frac{\pi}{2}\right) \qquad \cos x = \sin\left(x + \frac{\pi}{2}\right)$$

Dvojnásobný a poloviční úhel

Dvojnásobný úhel
$$\sin 2x = 2\sin x\cos x$$ $$\cos 2x = \cos^2 x - \sin^2 x$$
Poloviční úhel
$$\sin\frac{x}{2} = \sqrt{\frac{1-\cos x}{2}} \qquad \cos\frac{x}{2} = \sqrt{\frac{1+\cos x}{2}}$$ Znaménko před odmocninou se určí podle kvadrantu, ve kterém leží \(\frac{x}{2}\).

Dopočet ostatních funkcí

Příklad 1 · z jedné hodnoty dopočítat zbytek
Je dáno \(\sin x = \frac{2}{3}\),   \(x \in \left(\frac{\pi}{2};\ \pi\right)\). Urči \(\cos x\), \(\operatorname{tg} x\), \(\operatorname{cotg} x\), \(\sin 2x\), \(\cos 2x\).
\(\cos^2 x = 1 - \sin^2 x = 1 - \dfrac{4}{9} = \dfrac{5}{9}\)
/ ze základního vzorce
\(\cos x = -\dfrac{\sqrt{5}}{3}\)
/ 2. kvadrant → záporný!
\(\operatorname{tg} x = \dfrac{2/3}{-\sqrt{5}/3} = -\dfrac{2\sqrt{5}}{5}\)
/ usměrnit
\(\operatorname{cotg} x = -\dfrac{\sqrt{5}}{2}\)
/ převrácená hodnota
\(\sin 2x = 2 \cdot \frac{2}{3} \cdot \left(-\frac{\sqrt{5}}{3}\right) = -\dfrac{4\sqrt{5}}{9}\)
/ dvojnásobný úhel
\(\cos 2x = \dfrac{5}{9} - \dfrac{4}{9} = \dfrac{1}{9}\)
/ \(\cos^2x - \sin^2x\)
Nejdůležitější krok je určit znaménko podle kvadrantu. Ve druhém kvadrantu je \(\sin\) kladný, ale \(\cos\) záporný — proto ta záporná odmocnina. Pomůže si načrtnout jednotkovou kružnici.
\(\cos x = -\frac{\sqrt{5}}{3}\), \(\operatorname{tg} x = -\frac{2\sqrt{5}}{5}\), \(\operatorname{cotg} x = -\frac{\sqrt{5}}{2}\), \(\sin 2x = -\frac{4\sqrt{5}}{9}\), \(\cos 2x = \frac{1}{9}\)

Goniometrické rovnice

Základní princip
Goniometrické funkce jsou periodické, takže rovnice má nekonečně mnoho řešení. Vždy se proto zapisuje obecné řešení s \(k \in \mathbb{Z}\).

\(\sin\) a \(\cos\) mají periodu \(2\pi\) → přičítá se \(+2k\pi\)
\(\operatorname{tg}\) a \(\operatorname{cotg}\) mají periodu \(\pi\) → přičítá se \(+k\pi\)
Sinus a kosinus mají dvě řady řešení
Když vyjde \(\sin x = a\), existují v každé otáčce dvě hodnoty — nestačí jen jedna. Vyplatí se to ověřit na jednotkové kružnici.

Příklady — základní typy

Příklad 2 · rovnice s kotangentou
Řeš: \(\operatorname{cotg} x + 1 = 0\)
\(\operatorname{cotg} x = -1\)
/ osamostatnit
\(x = \dfrac{3}{4}\pi + k\pi\)
/ perioda \(\pi\)
U \(\operatorname{tg}\) a \(\operatorname{cotg}\) stačí jedna řada řešení — perioda je \(\pi\), takže se obě „větve" pokryjí automaticky.
\(x = \frac{3}{4}\pi + k\pi\), \(k \in \mathbb{Z}\)
Příklad 3 · nehezká hodnota (nutná kalkulačka)
Řeš: \(\sqrt{3}\sin x = 4 - 3\sqrt{2}\)
\(\sin x = \dfrac{4-3\sqrt{2}}{\sqrt{3}} \doteq -0{,}1401\)
/ osamostatnit
\(\arcsin(-0{,}1401) \doteq -0{,}1406\)
/ kalkulačka
\(x_1 = \pi + 0{,}1406 \doteq 3{,}282 + 2k\pi\)
/ 3. kvadrant
\(x_2 = 2\pi - 0{,}1406 \doteq 6{,}143 + 2k\pi\)
/ 4. kvadrant
Sinus je záporný → řešení leží ve 3. a 4. kvadrantu. Kalkulačka dá jen jednu hodnotu, druhou si musíš dopočítat z kružnice.
\(x_1 \doteq 3{,}28 + 2k\pi\),   \(x_2 \doteq 6{,}14 + 2k\pi\)
Příklad 4 · substituce za celý argument
Řeš: \(\sin\left(x - \frac{11}{6}\pi\right) = -\frac{\sqrt{3}}{2}\)
substituce \(t = x - \frac{11}{6}\pi\)
/ zjednodušit zápis
\(\sin t = -\dfrac{\sqrt{3}}{2}\)
/ tabulková hodnota
\(t_1 = \dfrac{4}{3}\pi + 2k\pi\),   \(t_2 = \dfrac{5}{3}\pi + 2k\pi\)
/ 3. a 4. kvadrant
\(x_1 = \dfrac{4}{3}\pi + \dfrac{11}{6}\pi = \dfrac{19}{6}\pi + 2k\pi\)
/ vrátit substituci
\(x_2 = \dfrac{5}{3}\pi + \dfrac{11}{6}\pi = \dfrac{7}{2}\pi = \dfrac{3}{2}\pi + 2k\pi\)
/ upravit do \(\langle 0; 2\pi)\)
Když je v argumentu složitější výraz, substituce ho zjednoduší. Nesmí se pak zapomenout vrátit zpět k původní neznámé!
\(x_1 = \frac{19}{6}\pi + 2k\pi\),   \(x_2 = \frac{3}{2}\pi + 2k\pi\)
Příklad 5 · tangenta se složeným argumentem
Řeš: \(3\operatorname{tg}\left(5 - \frac{3}{4}x\right) + 1 = 0\)
\(\operatorname{tg}\left(5-\frac{3}{4}x\right) = -\dfrac{1}{3}\)
/ osamostatnit
\(\operatorname{tg}\left(\frac{3}{4}x - 5\right) = \dfrac{1}{3}\)
/ \(\operatorname{tg}\) je lichá
\(\frac{3}{4}x - 5 = \arctan\frac{1}{3} \doteq 0{,}3218 + k\pi\)
/ kalkulačka
\(\frac{3}{4}x \doteq 5{,}322 + k\pi\)
/ \(+5\)
\(x \doteq 7{,}096 + \frac{4}{3}k\pi\)
/ \(\cdot\frac{4}{3}\)
Využili jsme, že \(\operatorname{tg}\) je lichá funkce: \(\operatorname{tg}(-u) = -\operatorname{tg}(u)\). Tím se zbavíme mínusu před závorkou. Pozor — perioda se na konci taky násobí \(\frac{4}{3}\)!
\(x \doteq 7{,}10 + \frac{4}{3}k\pi\), \(k \in \mathbb{Z}\)

Rovnice se substitucí

Když se v rovnici objeví druhé mocniny goniometrických funkcí, dá se často převést na obyčejnou kvadratickou rovnici.

Příklad 6 · převod na kvadratickou rovnici
Řeš: \(\operatorname{cotg}^2 x + 4\cos^2 x = 3\)
\(\operatorname{cotg}^2 x = \dfrac{\cos^2 x}{\sin^2 x} = \dfrac{\cos^2 x}{1-\cos^2 x}\)
/ vše na \(\cos\)
substituce \(t = \cos^2 x\)
\(\dfrac{t}{1-t} + 4t = 3\)
/ \(\cdot(1-t)\)
\(t + 4t - 4t^2 = 3 - 3t\)
/ roznásobit
\(-4t^2 + 8t - 3 = 0\)
/ \(D = 64-48 = 16\)
\(t_1 = \dfrac{1}{2}\),   \(t_2 = \dfrac{3}{2}\)
Kontrola smysluplnosti
\(t = \cos^2 x\) nemůže být větší než 1 — kořen \(t_2 = \frac{3}{2}\) tedy vypadá. Zůstává jen \(t_1 = \frac{1}{2}\).
\(\cos^2 x = \dfrac{1}{2} \Rightarrow \cos x = \pm\dfrac{\sqrt{2}}{2}\)
/ vrátit substituci
\(x = \dfrac{\pi}{4} + k\dfrac{\pi}{2}\)
/ všechny čtyři kvadranty
\(x = \frac{\pi}{4} + k\frac{\pi}{2}\), \(k \in \mathbb{Z}\)
Postup u rovnic se substitucí
1. Převést všechno na jednu goniometrickou funkci (nejčastěji přes \(\sin^2x + \cos^2x = 1\)).
2. Zavést substituci a vyřešit kvadratickou rovnici.
3. Vyloučit kořeny mimo obor hodnot (\(\sin\) a \(\cos\) jsou vždy v \(\langle-1;1\rangle\)).
4. Vrátit substituci a najít všechna řešení včetně periody.

Goniometrické nerovnice

Řeší se stejně jako rovnice — ale graficky
Postup je stejný jako u rovnice, jen místo jednoho bodu hledáme interval. Nejspolehlivější je načrtnout si graf nebo jednotkovou kružnici a odečíst, kde je funkce nad (nebo pod) danou hodnotou.
Nezapomeň na periodu
Výsledkem není jeden interval, ale nekonečně mnoho — zapisuje se s \(+2k\pi\) (u \(\sin\), \(\cos\)) nebo \(+k\pi\) (u \(\operatorname{tg}\), \(\operatorname{cotg}\)).
