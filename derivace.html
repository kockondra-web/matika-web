Derivace funkce \(f\) v bodě \(x_0\) je definována jako limita podílu přírůstků:

Definice
$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$$

Geometrický význam: derivace v bodě je směrnice tečny ke grafu funkce v tomto bodě — vzniká jako limitní případ sečny procházející dvěma body grafu, když se tyto body k sobě přibližují.

Tabulka derivací základních funkcí
\(y=c\)\(y'=0\)
\(y=x^n\)\(y' = n \cdot x^{n-1}\)
\(y=\sin x\)\(y'=\cos x\)
\(y=\cos x\)\(y'=-\sin x\)
\(y=\operatorname{tg} x\)\(y'=\dfrac{1}{\cos^2 x}\)
\(y=e^x\)\(y'=e^x\)
\(y=a^x\)\(y' = a^x \cdot \ln a\)
\(y=\ln x\)\(y'=\dfrac{1}{x}\)
\(y=\log_a x\)\(y'=\dfrac{1}{x \ln a}\)
Pravidla pro derivování
Součet/rozdíl: \((f\pm g)' = f'\pm g'\)
Součin: \((f\cdot g)' = f'g + fg'\)
Podíl: \(\left(\dfrac{f}{g}\right)' = \dfrac{f'g-fg'}{g^2}\)
Složená funkce (řetězové pravidlo): \([f(g(x))]' = f'(g(x))\cdot g'(x)\)
Tečna a normála v bodě T = [x₀, f(x₀)]
Tečna: \(y - f(x_0) = f'(x_0)(x-x_0)\)
Normála: \(y - f(x_0) = -\dfrac{1}{f'(x_0)}(x-x_0)\)
Nejčastější chyba
Zapomenutí řetězového pravidla u složené funkce — např. u \(\sin(3x^2+1)\) nestačí zderivovat jen \(\sin\), musí se vynásobit i derivací vnitřní funkce \(3x^2+1\), tedy výsledek je \(\cos(3x^2+1)\cdot 6x\), ne jen \(\cos(3x^2+1)\).

Lehké příklady
1. Zderivujte \(f(x) = 3x^4 - 2x^2 + 5x - 7\)
1
Derivujeme člen po členu podle \((x^n)' = n\cdot x^{n-1}\), konstanta \(-7\) se deruje na \(0\).
✓
$$f'(x) = 12x^3 - 4x + 5$$
2. Zderivujte \(f(x) = \sin x + \cos x\)
1
Derivace součtu je součet derivací: \((\sin x)'=\cos x\), \((\cos x)' = -\sin x\)
✓
$$f'(x) = \cos x - \sin x$$
3. Zderivujte \(f(x) = x^2 \cdot e^x\) (pravidlo pro součin)
1
Označíme \(u = x^2\), \(v = e^x\), tedy \(u' = 2x\), \(v' = e^x\).
2
$$f'(x) = 2x\,e^x + x^2 e^x$$
✓
Po vytknutí \(e^x\): $$f'(x) = e^x\cdot x(2+x)$$
4. Zderivujte \(f(x) = \dfrac{\ln x}{x}\) (pravidlo pro podíl)
1
Označíme \(u=\ln x\), \(v=x\), tedy \(u' = \tfrac{1}{x}\), \(v'=1\).
✓
$$f'(x) = \frac{\frac{1}{x}\cdot x - \ln x}{x^2} = \frac{1-\ln x}{x^2}$$
5. Najděte rovnici tečny ke grafu \(f(x) = x^2\) v bodě \(x_0 = 1\)
1
Funkční hodnota: \(f(1) = 1\)
2
Derivace a její hodnota v bodě: \(f'(x) = 2x \Rightarrow f'(1) = 2\)
✓
Dosazení do rovnice tečny: $$y - 1 = 2(x-1) \Rightarrow y = 2x - 1$$
6. Zderivujte \(f(x) = \sqrt{x} + \dfrac{1}{x^3}\)
1
Převedeme na mocniny: \(f(x) = x^{1/2} + x^{-3}\)
✓
$$f'(x) = \frac{1}{2\sqrt{x}} - \frac{3}{x^4}$$
Těžké příklady
7. Zderivujte \(f(x) = \sin(3x^2+1)\) (řetězové pravidlo)
1
Vnější funkce \(\sin(u)\) má derivaci \(\cos(u)\), vnitřní \(u=3x^2+1\) má derivaci \(u'=6x\).
✓
$$f'(x) = \cos(3x^2+1)\cdot 6x$$
8. Zderivujte \(f(x) = e^{\cos x}\cdot x^3\) (součin + řetězové pravidlo)
1
\(u = e^{\cos x} \Rightarrow u' = e^{\cos x}\cdot(-\sin x)\) (řetězové pravidlo), \(v = x^3 \Rightarrow v' = 3x^2\)
2
$$f'(x) = e^{\cos x}(-\sin x)\cdot x^3 + e^{\cos x}\cdot 3x^2$$
✓
Po vytknutí: $$f'(x) = e^{\cos x}\left(3x^2 - x^3\sin x\right)$$
9. Zderivujte \(f(x) = \dfrac{\ln(x^2+1)}{e^{2x}}\) (podíl + řetězové pravidlo v obou částech)
1
Čitatel: \(u = \ln(x^2+1) \Rightarrow u' = \dfrac{2x}{x^2+1}\). Jmenovatel: \(v = e^{2x} \Rightarrow v' = 2e^{2x}\)
✓
Po zjednodušení: $$f'(x) = e^{-2x}\left[\frac{2x}{x^2+1} - 2\ln(x^2+1)\right]$$
10. Najděte tečnu i normálu ke grafu \(f(x) = \ln(x)\cdot \sin x\) v bodě \(x_0 = \pi/2\)
1
Derivace (pravidlo pro součin): \(f'(x) = \frac{1}{x}\sin x + \ln x \cdot \cos x\)
2
Dosazením \(x_0=\pi/2\) (\(\sin\frac{\pi}{2}=1\), \(\cos\frac{\pi}{2}=0\)): \(f'(\pi/2) = \frac{2}{\pi}\), \(f(\pi/2) = \ln\frac{\pi}{2}\)
✓
Tečna: $$y - \ln\tfrac{\pi}{2} = \frac{2}{\pi}(x-\tfrac{\pi}{2})$$ Normála: $$y - \ln\tfrac{\pi}{2} = -\frac{\pi}{2}(x-\tfrac{\pi}{2})$$
11. Zderivujte \(f(x) = x^{\sin x}\) (logaritmická derivace)
1
Zlogaritmujeme obě strany: \(\ln y = \sin x \cdot \ln x\)
2
Derivujeme obě strany podle x: \(\dfrac{y'}{y} = \cos x \cdot \ln x + \dfrac{\sin x}{x}\)
✓
Vynásobením \(y=x^{\sin x}\): $$f'(x) = x^{\sin x}\left(\cos x \cdot \ln x + \frac{\sin x}{x}\right)$$
