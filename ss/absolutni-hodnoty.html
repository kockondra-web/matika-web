Rovnice a nerovnice s absolutními hodnotami

Definice absolutní hodnoty a její geometrický význam, grafy funkcí \(|f(x)|\) a \(f(|x|)\), početní i grafické řešení lineárních a kvadratických rovnic a nerovnic s absolutními hodnotami.

maturitní téma 5 · navazuje na lineární a kvadratické funkce

Definice a geometrický význam

Definice
$$|x| = \begin{cases} x & \text{pro } x \geq 0 \\ -x & \text{pro } x < 0 \end{cases}$$ Geometricky: \(|x|\) je vzdálenost čísla \(x\) od nuly na číselné ose. Proto je vždy nezáporná.
Nejčastější nedorozumění
\(-x\) neznamená „záporné číslo". Když je \(x = -5\), pak \(-x = 5\). Absolutní hodnota tedy záporná čísla otočí na kladná, kladná nechá být.

Transformace grafů

Dva různé zápisy, dvě různá pravidla — nepleť si je:

\(f(x) \to |f(x)|\)
Vše pod osou x se zrcadlově překlopí nahoru
\(f(x) \to f(|x|)\)
Pravá část se zrcadlově překlopí doleva
Jak si to zapamatovat
Absolutní hodnota kolem celé funkce \(|f(x)|\) → mění se výsledek (y-ové hodnoty) → překlápí se podle osy x.

Absolutní hodnota jen u \(x\) \(f(|x|)\) → mění se vstup → překlápí se podle osy y, přičemž levá půlka se zahodí.

Příklady — grafy funkcí

Příklad 1 · lineární funkce s více absolutními hodnotami
Sestroj graf: \(f: y = 13 - 2|x-1| + |x| - 4|x+3| + x\)
Nulové body jednotlivých absolutních hodnot: \(1,\ 0,\ -3\). Ty rozdělí osu na intervaly — mezi nimi je graf vždy přímka, stačí tedy spočítat hodnoty v několika bodech a spojit je.
\(x\)\(-5\)\(-3\)\(0\)\(1\)\(2\)
\(y\)\(-7\)\(5\)\(-1\)\(-1\)\(-5\)
\(f(-5) = 13 - 2\cdot6 + 5 - 4\cdot2 - 5 = -7\)
/ dosadit
\(f(-3) = 13 - 2\cdot4 + 3 - 0 - 3 = 5\)
/ vrchol
\(f(0) = 13 - 2 + 0 - 12 + 0 = -1\)
Lomená čára s vrcholy v bodech \([-3;\ 5]\), \([0;\ -1]\), \([1;\ -1]\)
Příklad 2 · kvadratická funkce v absolutní hodnotě
Sestroj graf: \(f: y = |x^2 + x - 12|\)
\(x^2+x-12 = (x-3)(x+4)\)
/ nulové body \(3,\ -4\)
vrchol v \(x = -0{,}5\)
/ střed mezi kořeny
\(f(-0{,}5) = -12{,}25 \to +12{,}25\)
/ překlopit nahoru
Části paraboly pod osou \(x\) (mezi kořeny) se překlopí nahoru — vznikne „hrb" s vrcholem v \(12{,}25\).
Parabola s překlopenou částí mezi \(-4\) a \(3\), maximum „hrbu" \(12{,}25\)
Příklad 3 · absolutní hodnota u proměnné
Sestroj graf: \(f: y = x^2 - 2|x| - 15\)
\(x^2 - 2|x| - 15\)
/ úprava na čtverec
\((|x|-1)^2 - 16\)
/ posun \(+1\) doprava, \(-16\) dolů
Nakreslíme parabolu \(y = x^2-2x-15\) pro \(x \geq 0\) a pak ji zrcadlově překlopíme doleva — vznikne symetrický tvar písmene W s minimy v \(\pm1\).
Nuly v \(\pm 5\), dvě minima v \([\pm1;\ -16]\), lokální maximum v \([0;\ -15]\)

Postup u rovnic a nerovnic

Čtyři kroky
1. Najdeme nulové body všech absolutních hodnot.
2. Rozdělíme osu na intervaly.
3. V každém intervalu absolutní hodnoty odstraníme (podle znaménka výrazu uvnitř) a rovnici vyřešíme.
4. Ověříme, jestli řešení leží ve svém intervalu — a pro jistotu dosadíme do původní rovnice.
Bez čtvrtého kroku to nemá cenu
Řešení, které vyjde v jednom intervalu, ale leží mimo něj, není řešením rovnice. Tohle je nejčastější zdroj ztracených bodů — viz příklad 5.

Příklady — lineární rovnice

Příklad 4 · jedna absolutní hodnota
Řeš v \(\mathbb{R}\): \(2 - |3x+6| = 2x - 1\)   nulový bod \(-2\)
\((-\infty;-2)\)\((-2;+\infty)\)
\(2 + (3x+6) = 2x-1\)\(2 - (3x+6) = 2x-1\)
\(3x + 8 = 2x - 1\)\(-3x - 4 = 2x - 1\)
\(x = -9\)\(-5x = 3\)
\(-9 \in\) intervalu ✓\(x = -\frac{3}{5} \in\) intervalu ✓
\(O = D = \mathbb{R}\), \(P = \left\{-9;\ -\frac{3}{5}\right\}\)
Příklad 5 · dvě absolutní hodnoty — past na ověření
Řeš v \(\mathbb{R}\): \(2|x+1| - 3x = 3|2-x| + 4\)   nulové body \(-1,\ 2\)
\((-\infty;-1)\)\((-1;2)\)\((2;+\infty)\)
\(-2(x+1)-3x = 3(2-x)+4\)\(2(x+1)-3x = 3(2-x)+4\)\(2(x+1)-3x = -3(2-x)+4\)
\(-5x-2 = 10-3x\)\(-x+2 = 10-3x\)\(-x+2 = 3x-2\)
\(x = -6\)\(x = 4\)\(x = 1\)
\(-6 \in (-\infty;-1)\) ✓\(4 \notin (-1;2)\) ✗\(1 \notin (2;\infty)\) ✗
Zkouška \(x=-6\):   \(2\cdot5 + 18 = 28\),   \(3\cdot8 + 4 = 28\)
✓ platí
Zkouška \(x=4\):   \(10 - 12 = -2\),   \(3\cdot2 + 4 = 10\)
✗ neplatí
Dvě ze tří „řešení" vypadla — proto se vždy musí ověřit, jestli výsledek leží ve svém intervalu.
\(O = D = \mathbb{R}\), \(P = \{-6\}\)
Příklad 6 · rovnice bez řešení
Řeš v \(\mathbb{R}\): \(2 - |2x+1| = 3|1-x| + x\)   nulové body \(-\frac{1}{2},\ 1\)
\(\left(-\infty;-\frac{1}{2}\right)\)\(\left(-\frac{1}{2};1\right)\)\((1;+\infty)\)
\(2+(2x+1) = 3(1-x)+x\)\(2-(2x+1) = 3(1-x)+x\)\(2-(2x+1) = -3(1-x)+x\)
\(4x = 0 \Rightarrow x = 0\)\(1-2x = 3-2x\)\(6x = 4 \Rightarrow x = \frac{2}{3}\)
\(0 \notin\) intervalu ✗\(1 = 3\) — nesmysl ✗\(\frac{2}{3} \notin\) intervalu ✗
\(O = D = \mathbb{R}\), \(P = \emptyset\) — rovnice nemá řešení
Příklad 7 · tři absolutní hodnoty
Řeš v \(\mathbb{R}\): \(|2x-4| - 2|x+1| = 3 - |2-x|\)   nulové body \(-1,\ 2\)
\((-\infty;-1)\)\((-1;2)\)\((2;+\infty)\)
\(-2x+4-2(-x-1) = 3-(2-x)\)\(-2x+4-2(x+1) = 3-(2-x)\)\(2x-4-2(x+1) = 3-(x-2)\)
\(6 = 1+x \Rightarrow x = 5\)\(-4x+2 = 1+x \Rightarrow x = \frac{1}{5}\)\(-6 = 5-x \Rightarrow x = 11\)
\(5 \notin\) intervalu ✗\(\frac{1}{5} \in\) intervalu ✓\(11 \in\) intervalu ✓
\(O = D = \mathbb{R}\), \(P = \left\{\frac{1}{5};\ 11\right\}\)
Příklad 8 · řešením je celý interval
Řeš v \(\mathbb{R}\): \(|4-x| - |x| = 3 - |2x-1|\)   nulové body \(0,\ \frac{1}{2},\ 4\)
\((-\infty;0)\)\(\left(0;\frac{1}{2}\right)\)\(\left(\frac{1}{2};4\right)\)\((4;\infty)\)
\(4-x+x = 3+2x-1\)\(4-x-x = 3+2x-1\)\(4-x-x = 3-2x+1\)\(-4+x-x = 3-2x+1\)
\(x = 1\)\(x = \frac{1}{2}\)\(4 = 4\)\(x = 4\)
✗ mimohraniceplatí celý intervalhranice
Ve třetím intervalu se rovnice zredukovala na identitu \(4=4\) — platí tedy pro každé \(x\) z toho intervalu. Krajní body \(\frac{1}{2}\) a \(4\) po dosazení také vyhovují.
\(O = D = \mathbb{R}\), \(P = \left\langle \frac{1}{2};\ 4 \right\rangle\)

Příklady — kvadratické rovnice

Příklad 9 · absolutní hodnota u proměnné
Řeš v \(\mathbb{R}\): \(x^2 + |x| - 2 = 0\)
\(x \geq 0\)\(x < 0\)
\(x^2+x-2 = 0\)\(x^2-x-2 = 0\)
\((x+2)(x-1)\)\((x-2)(x+1)\)
\(-2\) ✗   \(1\) ✓\(2\) ✗   \(-1\) ✓
\(O = D = \mathbb{R}\), \(P = \{-1;\ 1\}\)
Příklad 10 · celý výraz v absolutní hodnotě
Řeš v \(\mathbb{R}\): \(|x^2 - 5| = 4\)
\(x^2 - 5 = 4\)
/ první možnost
\(x^2 = 9 \Rightarrow x = \pm 3\)
\(x^2 - 5 = -4\)
/ druhá možnost
\(x^2 = 1 \Rightarrow x = \pm 1\)
Když je v absolutní hodnotě celý výraz a rovná se číslu, stačí rozepsat obě možnosti (\(+4\) a \(-4\)) — netřeba dělit na intervaly.
\(P = \{-3;\ -1;\ 1;\ 3\}\)
Příklad 11 · kvadratická rovnice s absolutní hodnotou uvnitř
Řeš v \(\mathbb{R}\): \(x^2 + 6x - 4|x+3| + 12 = 0\)   nulový bod \(-3\)
\(x < -3\)\(x \geq -3\)
\(x^2+6x-4(-x-3)+12 = 0\)\(x^2+6x-4(x+3)+12 = 0\)
\(x^2+10x+24 = 0\)\(x^2+2x = 0\)
\((x+6)(x+4)\)\(x(x+2)\)
\(-6\) ✓   \(-4\) ✓\(0\) ✓   \(-2\) ✓
Tady vyšla všechna čtyři řešení — každé leží ve svém intervalu. To se nestává často, o to důležitější je kontrola.
\(O = D = \mathbb{R}\), \(P = \{-6;\ -4;\ -2;\ 0\}\)

Příklady — nerovnice

Příklad 12 · základní nerovnice
Řeš v \(\mathbb{R}\): \(|1-2x| \leq 2\)   nulový bod \(\frac{1}{2}\)
\(x \leq \frac{1}{2}\)\(x > \frac{1}{2}\)
\(1-2x \leq 2\)\(-1+2x \leq 2\)
\(2x \geq -1 \Rightarrow x \geq -\frac{1}{2}\)\(2x \leq 3 \Rightarrow x \leq \frac{3}{2}\)
\(\left\langle -\frac{1}{2};\ \frac{1}{2} \right\rangle\)\(\left(\frac{1}{2};\ \frac{3}{2} \right\rangle\)
Výsledky z jednotlivých intervalů se sjednotí (na rozdíl od soustavy nerovnic, kde se hledá průnik).
\(O = D = \mathbb{R}\), \(P = \left\langle -\frac{1}{2};\ \frac{3}{2} \right\rangle\)
Příklad 13 · řešením jsou všechna reálná čísla
Řeš v \(\mathbb{R}\): \(3 - |1-x| \leq x+2\)   nulový bod \(1\)
\(x \leq 1\)\(x > 1\)
\(3-(1-x) \leq x+2\)\(3-(x-1) \leq x+2\)
\(2+x \leq x+2\)\(4-x \leq x+2\)
\(2 \leq 2\)\(2 \leq 2x \Rightarrow x \geq 1\)
platí vždy → \((-\infty;1\rangle\)platí celý interval → \((1;\infty)\)
V levém intervalu se \(x\) úplně vykrátilo a zbyla pravdivá nerovnost \(2 \leq 2\) — platí tedy pro všechna \(x\) z toho intervalu.
\(O = D = \mathbb{R}\), \(P = \mathbb{R}\)
Příklad 14 · dvě absolutní hodnoty
Řeš v \(\mathbb{R}\): \(2|x| - 4|1-x| \leq 3x+1\)   nulové body \(0,\ 1\)
\((-\infty;0\rangle\)\((0;1\rangle\)\((1;\infty)\)
\(-2x-4(1-x) \leq 3x+1\)\(2x-4(1-x) \leq 3x+1\)\(2x-4(x-1) \leq 3x+1\)
\(2x-4 \leq 3x+1\)\(6x-4 \leq 3x+1\)\(-2x+4 \leq 3x+1\)
\(x \geq -5\)\(x \leq \frac{5}{3}\)\(x \geq \frac{3}{5}\)
\(\langle -5;\ 0 \rangle\)celý \((0;1\rangle\)celý \((1;\infty)\)
\(O = D = \mathbb{R}\), \(P = \langle -5;\ +\infty)\)
Příklad 15 · kvadratická nerovnice s absolutní hodnotou
Řeš v \(\mathbb{R}\): \(x^2 - 5|x| + 6 < 0\)
\(x \geq 0\)\(x < 0\)
\(x^2-5x+6 < 0\)\(x^2+5x+6 < 0\)
\((x-2)(x-3) < 0\)\((x+2)(x+3) < 0\)
\((2;\ 3)\)\((-3;\ -2)\)
Graf je souměrný podle osy y — proto vyjdou dva symetrické intervaly. To je typický znak funkce s \(|x|\).
\(O = D = \mathbb{R}\), \(P = (-3;\ -2) \cup (2;\ 3)\)
