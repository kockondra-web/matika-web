Algebraický tvar

Imaginární jednotka
Zavádíme číslo \(i\), pro které platí \(i^2 = -1\). Díky němu jde počítat i s odmocninami ze záporných čísel.
Komplexní číslo
Komplexní číslo je dvojice \(z = a + bi\), kde \(a, b \in \mathbb{R}\).

\(a\) se nazývá reálná část — píše se \(\text{Re}(z) = a\)
\(b\) se nazývá imaginární část — píše se \(\text{Im}(z) = b\)

Pokud \(b = 0\), je \(z\) obyčejné reálné číslo (\(z \in \mathbb{R}\)).
Pokud \(a = 0\), je \(z = bi\) ryze imaginární.

Gaussova rovina

Komplexní číslo \(z = a+bi\) zobrazujeme jako bod (nebo vektor z počátku) v rovině, kde na vodorovnou osu nanášíme reálnou část a na svislou imaginární část.

Bod \(z = 3+i\): 3 jednotky doprava, 1 jednotka nahoru
Pozor
\(i\) je konkrétní, pevně daná hodnota (\(i^2=-1\)), ne proměnná. Nepočítej s ním jako s neznámým \(x\) — nedá se „vytknout" nebo řešit rovnici pro \(i\).

Operace s komplexními čísly

Pro celou sekci: \(z_1 = a+bi\),   \(z_2 = c+di\).

Rovnost
$$z_1 = z_2 \iff a = c \ \land\ b = d$$ Dvě komplexní čísla se rovnají, právě když se rovnají jejich reálné i imaginární části zvlášť.

Součet a rozdíl

Vzorce
$$z_1 + z_2 = (a+c) + (b+d)i$$ $$z_1 - z_2 = (a-c) + (b-d)i$$ Reálné části se sečtou/odečtou zvlášť, imaginární zvlášť — stejně jako u sčítání dvojčlenů.

Geometricky odpovídá součtu skládání vektorů (rovnoběžníkové pravidlo), rozdíl je součet s opačným vektorem \(-z_2\).

\(z_1+z_2\)
Vektory se sečtou „za sebe" — úhlopříčka rovnoběžníku
\(z_1-z_2 = z_1+(-z_2)\)
\(-z_2\) je \(z_2\) otočené o 180°

Součin

Vzorec
Roznásobí se jako dva dvojčleny, s využitím \(i^2=-1\): $$z_1 \cdot z_2 = (a+bi)(c+di) = ac + adi + bci + bdi^2 = (ac-bd) + (ad+bc)i$$
Příklad · součin
Vypočítej: \((-4+5i)(6-2i)\)
\((-4+5i)(6-2i) = -24 +8i +30i -10i^2\)
/ roznásobit
\(= -24 + 8i + 30i + 10\)
/ \(i^2=-1\)
\(= -14 + 38i\)
/ sečíst
\(-14+38i\)

Komplexně sdružené číslo

Definice
$$\overline{z} = a - bi$$ Ke komplexně sdruženému číslu dojdeš tak, že otočíš znaménko u imaginární části. Geometricky je to zrcadlový obraz podle reálné osy.

Podíl

Postup
Zlomek rozšíříme číslem komplexně sdruženým ke jmenovateli — tím se jmenovatel zbaví \(i\): $$\frac{z_1}{z_2} = \frac{a+bi}{c+di}\cdot\frac{c-di}{c-di} = \frac{ac+bd}{c^2+d^2} + \frac{bc-ad}{c^2+d^2}i$$
Příklad · podíl
Vypočítej: \(\dfrac{3+4i}{1-i}\)
\(\dfrac{3+4i}{1-i}\cdot\dfrac{1+i}{1+i}\)
/ rozšířit sdruženým \(1+i\)
\(= \dfrac{3+3i+4i+4i^2}{1-i^2} = \dfrac{-1+7i}{2}\)
/ roznásobit, \(i^2=-1\)
\(= -\dfrac{1}{2} + \dfrac{7}{2}i\)
Jmenovatel \((1-i)(1+i) = 1-i^2 = 2\) je po rozšíření vždy reálné číslo — proto se \(i\) ve jmenovateli „ztratí".
\(-\frac{1}{2} + \frac{7}{2}i\)

Mocniny čísla i

Základní mocniny
$$i^1 = i \qquad i^2 = -1 \qquad i^3 = -i \qquad i^4 = 1$$ Od páté mocniny se vzor opakuje po čtyřech: \(i^5=i,\ i^6=-1,\ i^7=-i,\ i^8=1,\ \dots\)
Mocniny \(i\) na jednotkové kružnici
Každá další mocnina = pootočení o 90°
Obecně (\(k \in \mathbb{N}_0\))
$$i^{4k}=1 \qquad i^{4k+1}=i \qquad i^{4k+2}=-1 \qquad i^{4k+3}=-i$$ Stačí vydělit exponent čtyřmi a podívat se na zbytek.
Příklad · vysoká mocnina
Urči \(i^{37}\) a \(i^{123}\)
\(37 = 4\cdot 9 + 1 \ \Rightarrow\ i^{37}=i^{4\cdot9+1}=i^1=i\)
/ zbytek 1
\(123 = 4\cdot 30 + 3 \ \Rightarrow\ i^{123}=i^{4\cdot30+3}=i^3=-i\)
/ zbytek 3
\(i^{37}=i\),   \(i^{123}=-i\)

Absolutní hodnota komplexního čísla

Definice
$$|z| = \sqrt{a^2+b^2}$$ Geometricky je \(|z|\) vzdálenost bodu \(z\) od počátku v Gaussově rovině — totéž jako délka vektoru.
Vlastnosti
$$|z| = |\overline{z}| = |{-z}| \qquad |z|=0 \iff z=0$$ $$|z_1 \cdot z_2| = |z_1|\cdot|z_2| \qquad \left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$$ $$|z_1+z_2| \leq |z_1|+|z_2| \quad \text{(trojúhelníková nerovnost)}$$
Příklad · modul součinu
Vypočítej \(|(2-i)(1+2i)|\) bez roznásobení
\(|(2-i)(1+2i)| = |2-i|\cdot|1+2i|\)
/ \(|z_1 z_2|=|z_1||z_2|\)
\(= \sqrt{5}\cdot\sqrt{5} = 5\)
Díky vlastnosti modulu součinu není třeba čísla vůbec roznásobovat.
5
Příklad · modul podílu
Vypočítej \(\left|\dfrac{i(3-4i)}{(1-3i)(2-i)}\right|\)
\(= \dfrac{|i|\cdot|3-4i|}{|1-3i|\cdot|2-i|}\)
/ vlastnosti modulu
\(= \dfrac{1\cdot 5}{\sqrt{10}\cdot\sqrt{5}} = \dfrac{5}{\sqrt{50}}\)
\(= \dfrac{5}{5\sqrt{2}} = \dfrac{1}{\sqrt2} = \dfrac{\sqrt2}{2}\)
/ zjednodušit
\(\dfrac{\sqrt2}{2}\)

Goniometrický a exponenciální tvar

Kromě algebraického tvaru \(a+bi\) lze komplexní číslo zapsat i pomocí jeho vzdálenosti od počátku a úhlu, který svírá s kladnou reálnou osou.

Tři tvary téhož čísla
Algebraický:   \(z = a+bi\)
Goniometrický:   \(z = |z|(\cos\varphi + i\sin\varphi)\)
Exponenciální:   \(z = |z|\,e^{i\varphi}\)

kde \(|z|=\sqrt{a^2+b^2}\) a \(\text{tg}\,\varphi = \dfrac{b}{a}\).
Pozor na kvadrant
\(\text{tg}\,\varphi=\frac{b}{a}\) dá jen referenční úhel. Skutečné \(\varphi\) (obvykle voleno z intervalu \(\langle0;2\pi)\)) je nutné dopočítat podle toho, ve kterém kvadrantu bod \(a+bi\) leží — podle znamének \(a\) a \(b\).
Příklad · G → E tvar
\(z_1 = 2\left(\cos\frac{2}{3}\pi + i\sin\frac{2}{3}\pi\right)\)   převeď na exponenciální tvar
\(z_1 = 2\,e^{\frac{2}{3}\pi i}\)
Příklad · E → G tvar
\(z_2 = 4\,e^{\frac{7}{4}\pi i}\)   převeď na goniometrický tvar
\(z_2 = 4\left(\cos\frac{7}{4}\pi + i\sin\frac{7}{4}\pi\right)\)
Příklad · G → A tvar
\(z_3 = 2\left(\cos\frac{5}{6}\pi + i\sin\frac{5}{6}\pi\right)\)   převeď na algebraický tvar
\(z_3 = 2\cdot\left(-\dfrac{\sqrt3}{2}\right) + 2\cdot\dfrac{1}{2}i\)
/ dosadit \(\cos,\sin\)
\(z_3 = -\sqrt3 + i\)
Příklad · G → A tvar (ve stupních)
\(z_4 = 12(\cos 240° + i\sin 240°)\)   převeď na algebraický tvar
\(z_4 = 12\cdot\left(-\dfrac12\right) + 12\cdot\left(-\dfrac{\sqrt3}{2}\right)i\)
/ dosadit \(\cos,\sin\)
\(z_4 = -6 - 6\sqrt3\,i\)
Příklad · A → G/E tvar
\(z_6 = -2\sqrt5 - 2\sqrt{15}\,i\)   převeď na goniometrický a exponenciální tvar
\(|z_6| = \sqrt{(2\sqrt5)^2+(2\sqrt{15})^2} = \sqrt{20+60}=\sqrt{80}=4\sqrt5\)
/ modul
\(\text{tg}\,\varphi = \dfrac{2\sqrt{15}}{2\sqrt5}=\sqrt3\), obě části záporné → 3. kvadrant
/ úhel
\(\varphi = \pi + \dfrac{\pi}{3} = \dfrac{4}{3}\pi\)
\(z_6 = 4\sqrt5\left(\cos\frac{4}{3}\pi+i\sin\frac{4}{3}\pi\right) = 4\sqrt5\,e^{\frac{4}{3}\pi i}\)

Operace v G/E tvaru a Moivreova věta

Sčítání a odčítání se v goniometrickém ani exponenciálním tvaru přímo nedají dělat — na to je potřeba algebraický tvar. Násobení a dělení jsou naopak v G/E tvaru jednodušší než v algebraickém.

Násobení
$$z_1\cdot z_2 = |z_1|\cdot|z_2|\big(\cos(\alpha+\beta)+i\sin(\alpha+\beta)\big) = |z_1|\cdot|z_2|\,e^{(\alpha+\beta)i}$$ Moduly se vynásobí, úhly se sečtou.
Dělení
$$\frac{z_1}{z_2} = \frac{|z_1|}{|z_2|}\big(\cos(\alpha-\beta)+i\sin(\alpha-\beta)\big) = \frac{|z_1|}{|z_2|}\,e^{(\alpha-\beta)i}$$ Moduly se vydělí, úhly se odečtou.
Příklad · násobení v G tvaru
Vypočítej \(z_1\cdot z_3\), kde \(z_1=2(\cos120°+i\sin120°)\), \(z_3=2(\cos150°+i\sin150°)\)
\(|z_1 z_3| = 2\cdot2 = 4\),   úhel \(= 120°+150° = 270°\)
/ moduly krát, úhly plus
\(z_1 z_3 = 4(\cos270°+i\sin270°) = 4(0 - i)\)
Zkouška roznásobením algebraických tvarů \(z_1=-1+\sqrt3 i\), \(z_3=-\sqrt3+i\) dá stejný výsledek.
\(z_1 z_3 = -4i\)
Moivreova věta
$$\big[|z|(\cos\varphi+i\sin\varphi)\big]^n = |z|^n\big(\cos n\varphi + i\sin n\varphi\big)$$ Umocňování v goniometrickém tvaru: modul se umocní, úhel se vynásobí exponentem.
Příklad · Moivreova věta
Vypočítej \(z_1^3\), kde \(z_1=2(\cos120°+i\sin120°)\)
\(|z_1^3| = 2^3 = 8\),   úhel \(= 3\cdot120° = 360°\)
/ modul na třetí, úhel krát 3
\(z_1^3 = 8(\cos360°+i\sin360°) = 8(1+0i)\)
Umocnit \((-1+\sqrt3i)^3\) přímo roznásobením by bylo výrazně pracnější — v tom je síla Moivreovy věty.
\(z_1^3 = 8\)
