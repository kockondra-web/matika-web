Předpis a vrcholový tvar

Dva tvary téže funkce
Obecný tvar: $$f: y = ax^2 + bx + c$$ Vrcholový tvar: $$f: y = a(x+m)^2 + n$$ Z vrcholového tvaru rovnou vyčteš vrchol paraboly \(V[-m;\ n]\).
Pozor na znaménko posunu
Posun po ose \(y\) je o \(n\) — tak, jak je napsané. Posun po ose \(x\) je ale o \(-m\), tedy opačně! U \(y = (x+3)^2\) se parabola posune o 3 doleva, ne doprava.

Význam koeficientu \(a\)

\(a > 0\)
konvexní — otevřená nahoru, vrchol je minimum
\(a < 0\)
konkávní — otevřená dolů, vrchol je maximum
Velikost \(|a|\)
větší \(|a|\) = užší, strmější parabola

Úprava na čtverec

Převod z obecného tvaru na vrcholový. Základní myšlenka: doplníme výraz tak, aby vznikl vzorec \((x \pm k)^2\), a to, co jsme přidali navíc, zase odečteme.

Postup ve třech krocích
1. Vytkneme \(a\) z prvních dvou členů (třetí necháme být).
2. V závorce doplníme na čtverec — přidáme \(\left(\frac{\text{koeficient u }x}{2}\right)^2\).
3. To, co jsme přidali (po vynásobení \(a\)), zase odečteme před závorkou.

Příklady — úprava na čtverec

Příklad 1 · nejjednodušší případ (\(a = 1\))
Uprav na čtverec: \(x^2 - 2x + 12\)
\(x^2 - 2x + 12\)
/ půlka z \(-2\) je \(-1\)
\((x-1)^2 = x^2-2x+1\)
/ přidali jsme \(+1\)
\((x-1)^2 + 12 - 1\)
/ jedničku odečteme
\((x-1)^2 + 11\)
\((x-1)^2 + 11\), vrchol \(V[1;\ 11]\)
Příklad 2 · s vytýkáním
Uprav na čtverec: \(2x^2 - 12x + 31\)
\(2(x^2 - 6x) + 31\)
/ vytknout 2
\(2(x^2-6x+9) + 31\)
/ doplnit \(\left(\frac{-6}{2}\right)^2 = 9\)
\(2(x-3)^2 + 31 - 18\)
/ přidali jsme \(2 \cdot 9 = 18\)
\(2(x-3)^2 + 13\)
Klíčové: odečítáme 18, ne 9 — devítka byla uvnitř závorky násobené dvojkou.
\(2(x-3)^2 + 13\), vrchol \(V[3;\ 13]\)
Příklad 3 · se zlomky
Uprav na čtverec: \(5x^2 - 2x + 3\)
\(5\left(x^2 - \frac{2}{5}x\right) + 3\)
/ vytknout 5
\(5\left(x^2 - \frac{2}{5}x + \frac{1}{25}\right) + 3\)
/ doplnit \(\left(\frac{1}{5}\right)^2\)
\(5\left(x - \frac{1}{5}\right)^2 + 3 - \frac{1}{5}\)
/ přidali jsme \(5 \cdot \frac{1}{25} = \frac{1}{5}\)
\(5\left(x - \frac{1}{5}\right)^2 + \frac{14}{5}\)
/ \(3 - \frac{1}{5} = \frac{14}{5}\)
\(5\left(x-\frac{1}{5}\right)^2 + \frac{14}{5}\), vrchol \(V\left[\frac{1}{5};\ \frac{14}{5}\right]\)
Příklad 4 · s určením oboru hodnot
Uprav na čtverec a urči \(D(f)\), \(H(f)\): \(f: y = 2x^2 - 8x + 13\)
\(2(x^2-4x) + 13\)
/ vytknout 2
\(2(x^2-4x+4) + 13 - 8\)
/ doplnit 4, odečíst \(2\cdot4\)
\(2(x-2)^2 + 5\)
Vrchol \(V[2;\ 5]\) — parabola je konvexní (\(a=2>0\)), takže 5 je nejmenší hodnota
\(2(x-2)^2+5\)  ·  \(D(f) = \mathbb{R}\), \(H(f) = \langle 5;\ +\infty)\)

Kvadratické rovnice — typy

Podle toho, které členy chybí
Bez lineárního členu (\(ax^2 + c = 0\)) → osamostatníme \(x^2\) a odmocníme

Bez absolutního členu (\(ax^2 + bx = 0\)) → vytkneme \(x\), součin je nula když je nula jeden činitel

Úplná (\(ax^2+bx+c=0\)) → diskriminant

Diskriminant

Vzorec
$$D = b^2 - 4ac \qquad x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$$
diskriminantpočet řešenígraf paraboly
\(D > 0\)dvě různá řešeníprotne osu \(x\) ve dvou bodech
\(D = 0\)jedno (dvojnásobné)dotýká se osy \(x\) ve vrcholu
\(D < 0\)žádné reálné řešeníosu \(x\) vůbec neprotne

Příklady — rovnice

Příklad 5 · bez lineárního členu
Řeš v \(\mathbb{R}\): \(2x^2 - 32 = 0\)
\(2x^2 = 32\)
/ \(+32\)
\(x^2 = 16\)
/ \(:2\)
\(x = \pm 4\)
/ odmocnit — obě znaménka!
\(P = \{-4;\ 4\}\)
Příklad 6 · bez absolutního členu
Řeš v \(\mathbb{R}\): \(2x^2 - 7x = 0\)
\(x(2x-7) = 0\)
/ vytknout \(x\)
\(x_1 = 0\)  nebo  \(2x-7 = 0\)
/ součin = 0
\(x_2 = \frac{7}{2}\)
Nikdy nedělte rovnici \(x\)! Přišli byste o řešení \(x = 0\).
\(O = D = \mathbb{R}\), \(P = \left\{0;\ \frac{7}{2}\right\}\)
Příklad 7 · úplná rovnice, hledání průsečíků
Najdi průsečíky grafu \(f: y = 6x^2 - 13x - 5\) s osami.
\(y = -5\)
/ osa \(y\): dosadíme \(x=0\)
\(6x^2-13x-5 = 0\)
/ osa \(x\): dosadíme \(y=0\)
\(D = 169 + 120 = 289\)
/ \(D = b^2-4ac\)
\(x_{1,2} = \dfrac{13 \pm 17}{12}\)
/ \(\sqrt{289} = 17\)
\(x_1 = \dfrac{30}{12} = \dfrac{5}{2}\), \(\quad x_2 = \dfrac{-4}{12} = -\dfrac{1}{3}\)
\(P_y[0;\ -5]\), \(\quad P_{x_1}\left[\frac{5}{2};\ 0\right]\), \(\quad P_{x_2}\left[-\frac{1}{3};\ 0\right]\)
Příklad 8 · rovnice se závorkami
Řeš v \(\mathbb{R}\): \((2x-1)(x-3)-(x-1) = (x+3)-(4+x)(x-3)\)
\(2x^2-7x+3-x+1 = x+3-(x^2+x-12)\)
/ roznásobit obě strany
\(2x^2-8x+4 = -x^2+15\)
/ sečíst
\(3x^2-8x-11 = 0\)
/ \(+x^2-15\)
\(D = 64+132 = 196\)
/ \(\sqrt{196} = 14\)
\(x_{1,2} = \dfrac{8 \pm 14}{6}\)
\(x_1 = \dfrac{22}{6} = \dfrac{11}{3}\), \(\quad x_2 = -1\)
\(O = \mathbb{R} = D\), \(P = \left\{\frac{11}{3};\ -1\right\}\)

Kvadratické nerovnice

Nejrychlejší cesta je načrtnout parabolu: najdeme kořeny (nebo zjistíme, že žádné nejsou), podíváme se, jestli je konvexní nebo konkávní, a z náčrtku vyčteme, kde je nad osou a kde pod ní.

Když \(D < 0\)
Parabola vůbec neprotne osu \(x\) — leží celá nad ní (pro \(a>0\)) nebo celá pod ní (pro \(a<0\)). Výsledek je pak vždy buď \(P = \mathbb{R}\), nebo \(P = \emptyset\), nic mezi tím.

Příklady — nerovnice

Příklad 9 · záporný diskriminant
Řeš v \(\mathbb{R}\): \(0{,}5x^2 - x + 1{,}5 < 0\)
\(\frac{1}{2}x^2 - x + \frac{3}{2} < 0\)
/ desetinná na zlomky
\(x^2 - 2x + 3 < 0\)
/ \(\cdot\,2\)
\(D = 4 - 12 = -8\)
/ \(D < 0\)
Parabola je konvexní (\(a>0\)) a osu \(x\) neprotne — leží tedy celá nad osou. Nikdy nemůže být záporná.
\(O = D = \mathbb{R}\), \(P = \emptyset\)
Příklad 10 · rozklad na součin
Řeš v \(\mathbb{R}\): \(x^2 + 2x - 8 \leq 0\)
\((x-2)(x+4) \leq 0\)
/ rozložit
\(x_1 = 2\), \(\quad x_2 = -4\)
/ kořeny
Hledáme, kde je parabola pod osou (nebo na ní) — to je mezi kořeny
\(O = \mathbb{R} = D\), \(P = \langle -4;\ 2 \rangle\)
Příklad 11 · záporný diskriminant, opačný případ
Řeš v \(\mathbb{R}\): \(x^2 - x + 4 > 0\)
\(D = 1 - 16 = -15\)
/ \(D < 0\) → neprotne osu \(x\)
Konvexní parabola, která neprotne osu \(x\), leží celá nad ní — je tedy vždy kladná, pro každé \(x\).
\(O = D = \mathbb{R}\), \(P = \mathbb{R}\)

Nerovnice v podílovém tvaru

Kombinace kvadratické nerovnice a tabulkové metody. Kvadratické výrazy nejdřív rozložíme na součin (nebo zjistíme, že mají záporný diskriminant a znaménko se tedy nemění), pak sestavíme znaménkovou tabulku.

Příklady — podílový tvar

Příklad 12 · čitatel se záporným diskriminantem
Řeš v \(\mathbb{R}\): \(\dfrac{-3x^2+x-4}{2x-5} \leq 0\)   podmínka \(x \neq \frac{5}{2}\)
\(D = 1 - 4\cdot(-3)\cdot(-4) = -47\)
/ diskriminant čitatele
\(a = -3 < 0\) a \(D < 0\)
/ konkávní, neprotne osu
čitatel je vždy záporný
\(\left(-\infty;\frac{5}{2}\right)\)\(\left(\frac{5}{2};\infty\right)\)
\(-3x^2+x-4\)−−
\(2x-5\)−+
podíl+−
Když má kvadratický výraz záporný diskriminant, nemění znaménko — do tabulky jde jako jeden blok.
\(O = \mathbb{R}\), \(D = \mathbb{R}\setminus\left\{\frac{5}{2}\right\}\), \(P = \left(\frac{5}{2};\ +\infty\right)\)
Příklad 13 · kvadratický čitatel i jmenovatel
Řeš v \(\mathbb{R}\): \(\dfrac{-4x^2+21x-5}{2x^2+5x+2} \geq 0\)
\(D_1 = 441 - 80 = 361\)
/ čitatel, \(\sqrt{361}=19\)
\(x_{1,2} = \dfrac{-21 \pm 19}{-8} \Rightarrow \dfrac{1}{4};\ 5\)
\(-4x^2+21x-5 = -(4x-1)(x-5)\)
/ rozklad čitatele
\(D_2 = 25-16 = 9\)
/ jmenovatel, \(\sqrt{9}=3\)
\(x_{3,4} = \dfrac{-5 \pm 3}{4} \Rightarrow -\dfrac{1}{2};\ -2\)
\(2x^2+5x+2 = (2x+1)(x+2)\)
/ podmínka \(x \neq -\frac{1}{2};\ -2\)
\((-\infty;-2)\)\(\left(-2;-\frac{1}{2}\right)\)\(\left(-\frac{1}{2};\frac{1}{4}\right)\)\(\left(\frac{1}{4};5\right)\)\((5;\infty)\)
\(-4x^2+21x-5\)−−−+−
\(2x^2+5x+2\)+−+++
podíl−+−+−
Kořeny čitatele (\(\frac{1}{4}\) a \(5\)) zahrnujeme, kořeny jmenovatele (\(-2\) a \(-\frac{1}{2}\)) ne.
\(O = \mathbb{R}\), \(D = \mathbb{R}\setminus\left\{-2;\ -\frac{1}{2}\right\}\), \(P = \left(-2;\ -\frac{1}{2}\right) \cup \left\langle \frac{1}{4};\ 5 \right\rangle\)
