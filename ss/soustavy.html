Obory O, D, P

Stejné jako u rovnic, jen s dvojicemi
\(O\) — obor řešitelnosti: kde řešení hledáme. U dvou neznámých je to \(\mathbb{R}^2\), u tří \(\mathbb{R}^3\).

\(D\) — definiční obor: co smíme dosadit (podmínky). U zlomků třeba \(\left(\mathbb{R}\setminus\{0\}\right)^3\).

\(P\) — obor pravdivosti: výsledek, tedy množina uspořádaných dvojic či trojic.
Pozor na zápis
Řešením není jedno číslo, ale uspořádaná n-tice — píše se do hranatých závorek v pořadí \([x;\ y]\), případně \([x;\ y;\ z]\). Prohození pořadí je jiné řešení!

Metody řešení

Tři základní
Dosazovací — z jedné rovnice vyjádříme neznámou a dosadíme do druhé. Nejlepší, když už je někde neznámá osamocená.

Sčítací — rovnice vynásobíme tak, aby se po sečtení jedna neznámá vyrušila. Nejrychlejší u soustav s více neznámými.

Srovnávací — z obou rovnic vyjádříme tutéž neznámou a výrazy položíme rovny.

Kolik má soustava řešení

výsledek úpravpočet řešenígeometricky (2 neznámé)
vyjde \(x = a\), \(y = b\)právě jednopřímky se protínají v bodě
vyjde \(0 = 0\)nekonečně mnohopřímky splývají
vyjde nesmysl (\(0 = 5\))žádné, \(P = \emptyset\)přímky jsou rovnoběžné

Příklady — lineární soustavy

Příklad 1 · nekonečně mnoho řešení
Řeš soustavu: \(y + \frac{1}{3}x = 2\)  a  \(\frac{1}{2}y + \frac{1}{6}x = 1\)
\(\frac{1}{2}y + \frac{1}{6}x = 1\)
/ \(\cdot(-2)\)
\(-y - \frac{1}{3}x = -2\)
/ přičíst k první rovnici
\(0 = 0\)
/ vždy pravda
Druhá rovnice je jen polovinou první — nepřináší žádnou novou informaci. Řešením je celá přímka, kterou zapíšeme parametricky.
\(O = D = \mathbb{R}^2\), \(P = \left\{\left[t;\ 2-\frac{1}{3}t\right],\ t \in \mathbb{R}\right\}\)
Příklad 2 · tři rovnice o třech neznámých (sčítací metoda)
Řeš soustavu: \(2x+3y-5z = 8\),   \(x+y+3z = 5\),   \(-3x-4y+3z = -10\)
Sečteme rovnice tak, aby se vyrušilo \(y\)
/ postupná eliminace
\(x + 15z = 10\)
/ zbyla rovnice o dvou neznámých
\(z = 3\)
/ z další kombinace
\(x + 45 = 10 \Rightarrow x = -35\)
/ dosadit \(z\)
\(-70 + 3y - 15 = 8 \Rightarrow 3y = 93\)
/ dosadit do první
\(y = 31\)
Zkouška: \(-35 + 31 + 9 = 5\) ✓  ·  \(105 - 124 + 9 = -10\) ✓
\(O = \mathbb{R}^3\), \(D = \mathbb{R}^3\), \(P = \{[-35;\ 31;\ 3]\}\)
Příklad 3 · symetrická soustava
Řeš soustavu: \(x+y-z = 11\),   \(x-y+z = 1\),   \(-x+y+z = 5\)
1. + 2. rovnice: \(2x = 12\)
/ \(y\) i \(z\) se vyruší
\(x = 6\)
2. + 3. rovnice: \(2z = 6\)
/ \(x\) i \(y\) se vyruší
\(z = 3\)
\(6 + y - 3 = 11\)
/ dosadit do první
\(y = 8\)
Když má soustava symetrickou strukturu (stejné koeficienty s různými znaménky), vyplatí se hledat dvojice, které se sečtením vyruší — ušetří to spoustu práce.
\(O = \mathbb{R}^3\), \(D = \mathbb{R}^3\), \(P = \{[6;\ 8;\ 3]\}\)

Soustavy se zlomky

Když jsou neznámé ve jmenovateli, nejjednodušší je zavést substituci — počítat s \(\frac{1}{x}\) jako s jednou proměnnou. Nezapomeň na podmínky!

Příklad 4 · neznámé ve jmenovateli
Řeš soustavu: \(\frac{4}{x} - \frac{3}{y} = 1\),   \(\frac{2}{x} + \frac{3}{z} = 4\),   \(\frac{3}{y} - \frac{1}{z} = 0\)
podmínky: \(x \neq 0\), \(y \neq 0\), \(z \neq 0\)
/ nulou se nedělí
Sečtením 1. a 3. rovnice: \(\frac{4}{x} - \frac{1}{z} = 1\)
/ \(\frac{3}{y}\) se vyruší
\(\frac{3}{z} = 3 \Rightarrow z = 1\)
/ kombinací s 2. rovnicí
\(\frac{3}{y} = 1 \Rightarrow y = 3\)
/ dosadit do 3. rovnice
\(\frac{14}{x} = 7 \Rightarrow x = 2\)
/ dosadit
Zkouška: \(\frac{4}{2} - \frac{3}{3} = 1\) ✓  ·  \(\frac{2}{2} + \frac{3}{1} = 4\) ✓  ·  \(\frac{3}{3} - \frac{1}{1} = 0\) ✓
\(O = \mathbb{R}^3\), \(D = \left(\mathbb{R}\setminus\{0\}\right)^3\), \(P = \{[2;\ 3;\ 1]\}\)

Soustava lineární a kvadratické rovnice

Postup
Vždy z lineární rovnice vyjádříme jednu neznámou a dosadíme do kvadratické. Vznikne kvadratická rovnice o jedné neznámé.
Geometrický význam
Lineární rovnice je přímka, kvadratická třeba kružnice nebo parabola. Počet řešení odpovídá počtu průsečíků:

2 řešení — přímka útvar protíná (sečna)
1 řešení — přímka se dotýká (tečna)
0 řešení — přímka útvar míjí

Příklady — lineární a kvadratická

Příklad 5 · přímka jako tečna kružnice
Řeš soustavu: \(x^2+y^2 = 100\),   \(3x+4y = 50\)
\(x = \dfrac{50-4y}{3}\)
/ vyjádřit z lineární
\(\left(\dfrac{50-4y}{3}\right)^2 + y^2 = 100\)
/ dosadit
\(\dfrac{2500-400y+16y^2}{9} + y^2 = 100\)
/ \(\cdot\,9\)
\(2500 - 400y + 25y^2 = 900\)
/ \(:25\)
\(y^2 - 16y + 64 = 0\)
/ vzorec \((y-8)^2\)
\(y = 8\) (dvojnásobný kořen)
\(3x = 50 - 32 = 18 \Rightarrow x = 6\)
/ dopočítat \(x\)
Vyšel dvojnásobný kořen — přímka se kružnice jen dotýká, je to tečna. Proto jediné řešení, ne dvě.
\(O = D = \mathbb{R}^2\), \(P = \{[6;\ 8]\}\)
Příklad 6 · dvě řešení
Řeš soustavu: \(15x^2 - 34xy + 15y^2 = 0\),   \(x+y = 4\)
\(y = 4 - x\)
/ vyjádřit z lineární
\(15x^2 - 34x(4-x) + 15(4-x)^2 = 0\)
/ dosadit
\(15x^2 - 136x + 34x^2 + 240 - 120x + 15x^2 = 0\)
/ roznásobit
\(64x^2 - 256x + 240 = 0\)
/ \(:16\)
\(4x^2 - 16x + 15 = 0\)
/ \(D = 256-240 = 16\)
\(x_{1,2} = \dfrac{16 \pm 4}{8} \Rightarrow \dfrac{5}{2};\ \dfrac{3}{2}\)
\(x = \frac{5}{2} \Rightarrow y = \frac{3}{2}\);   \(x = \frac{3}{2} \Rightarrow y = \frac{5}{2}\)
/ dopočítat
Ke každému kořenu musíme dopočítat druhou neznámou — výsledkem jsou dvě různé dvojice, ne čtyři čísla.
\(O = D = \mathbb{R}^2\), \(P = \left\{\left[\frac{5}{2};\ \frac{3}{2}\right];\ \left[\frac{3}{2};\ \frac{5}{2}\right]\right\}\)

Soustava dvou kvadratických rovnic

Když jsou obě rovnice kvadratické, často pomůže substituce — třeba položit \(t = y^2\) a získat tak obyčejnou kvadratickou rovnici.

Příklad 7 · substituce a čtyři řešení
Řeš soustavu: \(x^2 + 4y^2 = 20\),   \(xy = -4\)
\(x = -\dfrac{4}{y}\)
/ vyjádřit z druhé (\(y \neq 0\))
\(\dfrac{16}{y^2} + 4y^2 = 20\)
/ dosadit, \(\cdot\,y^2\)
\(4y^4 - 20y^2 + 16 = 0\)
/ \(:4\)
\(y^4 - 5y^2 + 4 = 0\)
/ substituce \(t = y^2\)
\(t^2 - 5t + 4 = 0 \Rightarrow t = 1;\ 4\)
/ zpět dosadit
\(y^2 = 1 \Rightarrow y = \pm1\);   \(y^2 = 4 \Rightarrow y = \pm2\)
\(y\)\(1\)\(-1\)\(2\)\(-2\)
\(x = -\frac{4}{y}\)\(-4\)\(4\)\(-2\)\(2\)
Substituce \(t = y^2\) změní rovnici čtvrtého stupně na obyčejnou kvadratickou. Pozor — po vyřešení se musí vrátit zpět k \(y\), a každé kladné \(t\) dá dvě hodnoty \(y\).
\(O = \mathbb{R}^2\), \(D = \mathbb{R}^2\), \(P = \{[-4;1];\ [4;-1];\ [-2;2];\ [2;-2]\}\)
Sčítací metoda i u kvadratických
Když mají obě rovnice tvar \(ax^2 + by^2 = c\), dá se použít sčítací metoda úplně stejně jako u lineárních — jen místo \(x\) a \(y\) eliminujeme \(x^2\) a \(y^2\). Výsledné hodnoty se pak musí odmocnit (a nezapomenout na obě znaménka).
